# Агент «Рубеж» — что изменилось и как запустить

Патч ложится поверх репозитория: распаковать в корень `Rubez.git`
(файлы встанут в `rubezh-2026-11-15/rubezh/...`, старые перезапишутся).

## Что сделано

**Фронтенд**
- `src/components/AgentChat.jsx` — агент в кабинете: шаги размышления, печать
  ответа, карточки «План / Уточнение / Разбор лога», подтверждение со списанием.
- `src/lib/agentPricing.js` — прайс и разбор карточек из ответа модели.
- `src/pages/Owner.jsx` — кабинет переведён на `<AgentChat>`, справа журнал
  событий, история НК и сборки.
- `src/pages/Home.jsx` — новый первый экран (диалог с агентом вместо пустого
  чата), секции «Работает сейчас / Следующий этап», тарифы, FAQ без
  противоречий про хостинг.
- `src/pages/Legal.jsx`, `src/lib/legal.js`, `src/pages/NotFound.jsx`,
  `src/routes.jsx` — страница документов (тексты-заглушки, блок реквизитов
  скрыт, пока не заполнен) и настоящая 404.
- `index.html` — title/description/OG/JSON-LD, шрифты через `preconnect`,
  `noscript`; `src/index.css` — стили агента, без внешнего `@import` шрифтов.

**Бэкенд**
- `functions/agentChat.ts` — провайдер модели вынесен в секреты
  (`AGENT_API_URL`, `AGENT_API_KEY`, `AGENT_MODEL`), цена возвращается
  в ответе (`prices`).
- `functions/_prompt.ts` — системная инструкция агента в одном месте
  (её же использует smoke-проверка).
- `functions/_pricing.ts` — прайс, единственный источник цены на сервере.
- `functions/applyAgentAction.ts` — списание строго по прайсу, идемпотентность
  по `clientRef` (повторное подтверждение не спишет дважды), 402 при нехватке НК.
- `entities/AgentEvent.json` — поля `service` и `clientRef`.

**Проверки и предпросмотр**
- `scripts/agent-smoke.ts` — реальный запрос к модели: проверяет, что карточка
  есть, услуга из прайса, цена клиента и сервера совпадают, модель не называет
  цену в тексте.
- `scripts/agent-preview.ts` + `preview/agent-ux-demo.html` — кликабельный
  кабинет с живым агентом: страница ходит в локальный `/api/agent`, ключ
  остаётся на сервере.

## Настройка

`.env.local` в корне приложения (в git не попадает):

```
AGENT_API_URL=https://agenthere.ru/v1
AGENT_API_KEY=<ключ шлюза>
AGENT_MODEL=deepseek-v4-flash
```

В проде те же три значения заводятся секретами окружения функций.
`NODUL_API_KEY` продолжает работать как fallback для ключа.

## Команды

```
npm install
npm run build          # сборка (нужны VIBELI_APP_ID / VIBELI_GATEWAY_URL)
npm run agent:smoke    # живой прогон агента + проверка формата ответа
npm run agent:preview  # http://127.0.0.1:8787 — кабинет с настоящей моделью
```

Smoke можно прогнать на своём вопросе:

```
node --experimental-strip-types scripts/agent-smoke.ts "построй арену на 16 игроков"
```

## Что осталось за владельцем

- Тексты документов (`src/lib/legal.js`) — черновики, нужна проверка юристом.
- Курс НК к рублю и условия тарифов — решение владельца.
- Хостинг серверов (Э-2) агентом пока не обещается: сейчас он собирает план,
  разбирает логи и считает смету.
